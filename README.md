# AI Interview Preparation Assistant

AI Interview Preparation Assistant is an AI-powered web application designed to help students and job seekers prepare for technical interviews. The system analyzes a candidate's resume, identifies relevant skills, generates personalized interview questions, evaluates answers, and provides AI-based feedback.

## Key Features

- User registration and secure login
- Resume PDF upload and text extraction
- Automatic skill detection from resumes
- Job-role selection
- AI-generated personalized interview questions
- 15-minute interview timer
- AI-based answer evaluation
- Technical and communication scoring
- Personalized feedback for each answer
- Interview results and history
- Detailed interview performance records
- MySQL database for storing user and interview data
- Secure password hashing and resume upload validation

## Objective

The objective of this project is to provide a personalized and interactive interview preparation platform that helps candidates practice job-specific questions and improve their technical knowledge and communication skills through AI-powered evaluation.

This project is suitable for students, fresh graduates, and job seekers preparing for technical interviews.
